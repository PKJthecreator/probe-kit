# static-tool — 설치·인터넷 없이 브라우저로 여는 업무 도구(파일 → 보고 초안)

쓰는 때: 담당자가 "공용 PC, 인터넷 안 됨, 설치 불가, 크롬만", "파일을 넣으면 메신저에 붙일 보고·인계 초안이 나오면 된다"고 할 때. 서버(`../web-api`)를 띄울 수 없는 환경의 기본값이다.
첫 명령: `node --test` (판정 함수 테스트) → `node build.mjs` (→ `dist/tool.html` 한 파일) → 크롬에서 그 파일을 열어 실제 데이터로 확인.
필요: Node 18+ (테스트·빌드에만). 결과물은 HTML 한 파일이라 받는 쪽은 아무것도 설치하지 않는다.

| 파일 | 하는 일 |
|---|---|
| `lib.js` | 순수 함수: CSV(BOM·따옴표·헤더 앞 메타·손상 줄 줄번호), 시각(UTC `Z`→KST, 엑셀 `H:mm`), 반열린 구간, 반올림 판정(경계 포함), 간격 묶음, 완전 중복 제거, 전화번호 가림, 줄 수 제한 보고(`[미확인]`/`[확인]`) |
| `tool.html` | 파일 여러 개 선택 → 알림 → 판정 필요 항목 확인 체크 → 일반 텍스트 보고 → 복사 버튼. 외부 호출·저장소 없음 |
| `build.mjs` | `tool.html`+`lib.js` → `dist/tool.html` 한 파일. `--vite dist`면 Vite 빌드 결과를 `dist/single.html` 한 파일로(기본 `dist/index.html`은 `file://`로 열면 빈 화면). 외부 주소·저장소 사용을 검사 |
| `lib.test.mjs` | `node --test`로 경계 규칙 검증 |

과제가 Vite+React 골격을 줬다면: 판정·계산은 `src/lib/*.ts` 순수 함수(+ 그 골격의 테스트 도구), 화면은 React, 빌드 뒤 `node ~/probe-kit/templates/static-tool/build.mjs --vite dist`로 한 파일을 만들고 크롬으로 열어 본다. 골격을 버리고 이 폴더 방식으로 바꾸면 그 이유를 과제의 `docs/DECISIONS.md`에 적는다.

## 기술 후보
| 층 | 후보 | 언제 |
|---|---|---|
| 형태 | **HTML 한 파일(이 뼈대)**, Vite 빌드 + 한 파일 인라인, 서버(FastAPI) | 설치·서버가 안 되면 HTML 한 파일. 서버는 담당자가 상시 서버를 허용할 때만 |
| 입력 | **`<input type=file multiple>` + FileReader** | 원본은 읽기만, 공유폴더 파일을 열 때마다 넣는다 |
| 보관 | **저장 안 함(열 때마다 다시 계산)**, 파일로 내려받기 | localStorage·IndexedDB는 담당자·IT가 허용할 때만 |
| 출력 | **일반 텍스트 + 복사 버튼**, 표·그래프 | 메신저에 붙이면 표가 깨진다. 담당자가 정한 양식·순서·줄 수를 그대로 |
| 테스트 | **node --test(설치 불필요)**, vitest(골격에 있으면) | 경계 규칙마다 한 줄 |

## 현업 수준 체크
1. 런타임 외부 호출(LLM API·CDN·웹폰트) 없음, 브라우저 저장소 없음, `build.mjs` PASS
2. 받는 사람 환경 그대로 확인: 만든 HTML을 `file://`로 열어 실제 제공 데이터로 돌려 봤다(서버·Node 없이)
3. 판정·계산은 `lib`의 순수 함수, 기준값(분·점·줄 수·적용 시각)은 이름 있는 상수, 경계 규칙마다 테스트
4. 잘못된 입력은 조용히 버리지 않는다: 못 읽은 줄·파일·빈 구간을 건수와 위치(파일·줄 번호)로 보고에 적고 나머지는 계속 처리
5. 사람이 정할 것(조치·해제·원인·재작업 판단)은 도구가 문장으로 만들지 않는다. 판정 필요 항목은 확인 체크, 안 하면 `[미확인]`
6. 데이터 속 이름·사번·전화번호·접속키는 화면·보고·로그·테스트 데이터·문서·커밋 메시지에 나오지 않는다(테스트에는 가짜 값)
7. 출력 형식(섹션 순서·줄 수·시각 표기·넘칠 때 접는 규칙)을 담당자 답과 한 줄씩 대조했다
