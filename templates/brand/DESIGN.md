# DESIGN.md — SK hynix 사내 업무 화면 (AI가 화면을 만들기 전에 읽는다)

값은 `tokens.css` 변수로만 쓴다(색 코드를 화면 파일에 직접 쓰지 않는다). 확인일 2026-11-03.

## 1. 분위기
- 사내 업무 도구: 구성원·운영자가 매일 쓰는 조회·처리 화면. 랜딩 페이지처럼 꾸미지 않는다.
- 흰 바탕 + 회색 면 + 진한 글자, 색은 강조에만. 정보 밀도는 높게, 장식은 적게.
- 말투: 짧고 사실대로("3건 남음", "09:10 출발"). 회사 슬로건 "Technology Innovator for a Better World", 가치 Tenacity·Advanced Tech.·Prosperity Together는 소개 문구가 필요할 때만.

## 2. 색 (역할별)
| 변수 | 값 | 출처 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|---|---|
| `--brand` | #EA002C SK Red (PANTONE 186C) | CI | 로고, 활성 메뉴 밑줄, 얇은 강조선 | 버튼 배경 전체, 오류 표시 |
| `--brand-2` | #F47725 SK Orange (PANTONE 158C) | CI | 글자 로고 둘째 단어(공식 CI도 'hynix'가 주황 — 로고는 대비 기준 예외), 그래프 강조 1계열, 장식 | 본문·버튼·안내 **글자색**(대비 2.8:1) |
| `--primary` | #4747B3 | 사이트 | 주 버튼, 링크, 체크박스, 포커스 | 큰 면적 배경 |

- CI 보조색(그래프 계열이 여러 개 필요할 때만): Yellow #FBBC05, Green #B3CF0A, Teal #009A93, Blue #0072C6, Navy #0E306D, Purple #68127A.

- 상태는 색만으로 구분하지 않는다: `✓ 정상`, `! 주의`, `✕ 오류`처럼 기호+글자.

## 3. 글꼴
- 공식 사이트: Roboto(영문·숫자) + Noto Sans KR(한글). 스택은 `--font-body` 한 곳. 시험 PC에 없으면 맑은 고딕으로 대체된다.
- 크기 단계(사이트 관측): 본문 16, 보조 14, 소제목 18·20, 제목 24·28, 큰 숫자 40px. 굵기 400/500/700.
- 숫자 열은 오른쪽 정렬 + `font-variant-numeric: tabular-nums`.

## 4. 레이아웃
- 헤더: 흰 바탕, 높이 82px(좁은 화면은 자동), 왼쪽 로고 한 곳, 메뉴, 오른쪽 사용자·로그아웃.
- 본문 최대 폭 1100px, 카드(흰 바탕·1px 선·모서리 4px), 카드 사이 16px.
- 중단점 1024·768·540px. 768px 아래는 1단, 표는 가로 스크롤.
- 로고 여백: 워드마크 'K' 높이를 X라 하면 사방 0.5X(좁으면 0.25X). 로고를 늘리거나 색을 바꾸지 않는다.

## 5. 부품
- 버튼: 주 버튼 하나만 `--primary` 채움, 나머지는 테두리. 높이 44px. 누르는 중엔 disabled + "…중" 글자.
- 입력: 위에 라벨, 아래에 힌트·오류(✕ + 어느 칸이 왜). 비밀번호 규칙은 입력 아래 체크리스트.
- 표: 머리 `--surface-2`, 행 구분선, 빈 결과·로딩·오류 문구를 표 자리에 같은 모양으로.
- 배지: 테두리+글자(채우지 않음). 예 운행 중 / 만석 / 지연 / 미배정.
- 차트: 외부 CDN 없이 인라인 SVG나 서버가 만든 PNG. 계열이 하나면 `--primary`, 강조 하나만 `--brand-2`.
- 아이콘: 글자 기호(✓ ✕ ! → ↗) 먼저. 그림 아이콘이 꼭 필요하면 Lucide(ISC)·Tabler(MIT) 인라인 SVG. 출처 표시 의무가 있는 무료 아이콘은 쓰지 않는다.

## 6. UX 규칙(검증된 원칙을 화면 규칙으로)
- 선택지를 줄인다: 한 화면의 주요 행동은 1~2개, 메뉴는 7개 이내(Hick).
- 자주 누르는 버튼은 크고 가깝게, 위험한 버튼은 떨어뜨리고 확인을 받는다(Fitts).
- 남들이 쓰는 모양을 따른다: 로그인 = 아이디·비밀번호·아이디 저장·찾기·가입 링크(Jakob).
- 0.4초 안에 반응을 보인다: 누르면 즉시 로딩 상태(Doherty).
- 긴 숫자·목록은 묶어 보여 준다: 시간대별·노선별 그룹(Chunking).

## 7. 하지 말 것
- 그라데이션·네온·유리 효과·큰 그림자·과한 애니메이션(`prefers-reduced-motion` 존중).
- 로고를 여러 곳에 반복, 로고 변형, SK Orange 글자.
- 서버 값을 innerHTML로 넣기(textContent만).
- 공식 사이트의 CSS·JS·이미지 파일을 복사해 넣기(저작물). 값과 규칙만 이 문서처럼 다시 쓴다.
